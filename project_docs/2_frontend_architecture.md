## Фронтенд

Фронтенд — это одностраничное приложение (SPA), созданное с помощью Vue.js 3 (с использованием Composition API и `<script setup>`), Vite для сборки и Pinia для управления состоянием.

### `main.ts`
Точка входа в приложение. Инициализирует Vue, Pinia и монтирует корневой компонент `App.vue`.

### `App.vue`
Корневой компонент приложения. Он определяет общую структуру страницы, включая заголовок, основную область контента и глобальные компоненты, такие как `ThemeSwitcher`, `Tooltip`, `ToastContainer` и `ActionHint`.

**Зависимости:**
*   **Stores:** `useContentStore`, `useNavigationStore`.
*   **Components:** `ActionsBar`, `StoriesSidebar`, `ThemeSwitcher`, `StoryDashboard`, `ChapterDashboard`, `SceneDashboard`, `FrameSidebar`, `FrameEditor`, `Tooltip`, `ToastContainer`, `ActionHint`.

---

### **Хранилища (Stores - `src/stores`)**
Pinia используется для глобального управления состоянием.

*   **`actionHint.ts`**: Управляет состоянием подсказок о доступных действиях.
*   **`content.ts`**: Отвечает за хранение, получение и обновление основного контента (истории, главы, сцены). Взаимодействует с API через `mock-api.ts`.
*   **`navigation.ts`**: Управляет состоянием навигации и пользовательского интерфейса. Отслеживает активную историю, главу, сцену и текущее представление (например, `frame`).
*   **`theme.ts`**: Управляет переключением между светлой и темной темами.
*   **`tooltip.ts`**: Управляет состоянием и содержимым глобальных всплывающих подсказок.
*   **`toast.ts`**: Управляет уведомлениями (всплывающими сообщениями).

---

### **Сервисы (Services - `src/services`)**

*   **`mock-api.ts`**: Имитирует бэкенд API. Содержит статические данные и логику для их "обновления" с искусственной задержкой, чтобы симулировать сетевые запросы. Это позволяет разрабатывать фронтенд независимо от бэкенда.

---

### **Библиотеки (Libraries - `src/lib`)**

*   **`generation-flags.ts`**: Определяет константы для флагов генерации (`GENERATION_FLAGS`), которые используются для управления процессом регенерации контента. Каждый флаг имеет ID, имя и иконку.
*   **`prompt-templates.ts`**: Определяет структуру и шаблоны для промптов, используемых при генерации контента.

---

### **Компоненты (Components - `src/components`)**

#### Основные компоненты

*   **`ActionsBar.vue`**: Боковая панель действий, которая отображает кнопки для выполнения основных операций в зависимости от текущего контекста (например, "Generate", "Save").
    *   *Зависимости:* `useNavigationStore`, `useActionHintStore`.
*   **`FrameEditor.vue`**: Основная область для редактирования кадров сцены. Включает в себя `TimelineView` для управления кадрами и `FrameDetailsSidebar` для редактирования детальной информации о выбранном кадре.
    *   *Зависимости:* `useContentStore`, `useNavigationStore`, `TimelineView`, `FrameDetailsSidebar`.
*   **`FrameSidebar.vue`**: Боковая панель, отображающая список кадров (пока не реализовано) в текущей сцене, когда активен `FrameEditor`.
*   **`PromptEditor.vue`**: Компонент для редактирования структурированных промптов. Используется в `FrameDetailsSidebar`.
*   **`StoriesSidebar.vue`**: Боковая панель, отображающая иерархический список историй, глав и сцен. Позволяет пользователю перемещаться по контенту.
    *   *Зависимости:* `useContentStore`, `useNavigationStore`, `StoriesView`.
*   **`StoriesView.vue`**: Компонент внутри `StoriesSidebar`, который отображает список всех историй и позволяет создавать новые.
*   **`ThemeSwitcher.vue`**: Кнопка для переключения темы оформления (светлая/темная).
    *   *Зависимости:* `useThemeStore`.

#### Панели управления (`src/components/dashboards`)
Эти компоненты отображают информацию о выбранном элементе (истории, главе или сцене) в основной области контента.

*   **`StoryDashboard.vue`**: Показывает детали активной истории и список ее глав.
*   **`ChapterDashboard.vue`**: Показывает детали активной главы и список ее сцен.
*   **`SceneDashboard.vue`**: Показывает детали активной сцены и (в будущем) ее кадры.

#### Временная шкала (`src/components/timeline`)
Компоненты, связанные с представлением и редактированием временной шкалы в `FrameEditor`.

*   **`TimelineView.vue`**: Центральный компонент, который отображает элементы (кадры) в виде вертикальной временной шкалы. Управляет вставкой новых элементов и выбором существующих для регенерации.
    *   *Зависимости:* `TimelineItem`, `InsertionPoint`, `InsertionForm`.
*   **`TimelineItem.vue`**: Представляет один элемент на временной шкале. Отображает его название, статус и панель флагов (`FlagPanel`).
    *   *Зависимости:* `FlagPanel`.
*   **`InsertionPoint.vue`**: "Точка вставки" на временной шкале, которая позволяет пользователю инициировать добавление новых элементов.
*   **`InsertionForm.vue`**: Форма, которая появляется после нажатия на `InsertionPoint`. Позволяет указать количество и описание для вставляемых элементов.
*   **`FrameDetailsSidebar.vue`**: Боковая панель, которая открывается в `FrameEditor` для редактирования детального промпта выбранного кадра (`TimelineItem`).
    *   *Зависимости:* `PromptEditor`.

#### UI-компоненты (`src/components/ui`)
Переиспользуемые, базовые компоненты пользовательского интерфейса.

*   **`FlagPanel.vue`**: Панель, которая управляет выбором флага для регенерации. Отображает активный флаг и раскрывается для показа всех доступных вариантов.
    *   *Зависимости:* `FlagButton`.
*   **`FlagButton.vue`**: Кнопка, представляющая один флаг генерации.
*   **`Tooltip.vue`**: Глобальный компонент для отображения всплывающих подсказок по всему приложению. Управляется через `useTooltipStore`.
*   **`Toast.vue`** и **`ToastContainer.vue`**: Компоненты для системы уведомлений (всплывающие сообщения).
*   **`ActionHint.vue`**: Компонент для отображения контекстных подсказок о действиях.
