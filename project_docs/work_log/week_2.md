## 2. Рефакторинг и структурирование бэкенда

**Дата:** ~ 13.02.2026 - 13.02.2026

После первоначальной реализации базовой функциональности генерации сюжета основной задачей стал рефакторинг бэкенда для приведения его к стандартной, чистой и масштабируемой архитектуре. Это было необходимо для дальнейшего расширения проекта, добавления новых моделей данных и бизнес-логики.

### 2.1. Анализ и планирование

*   **Выявлены проблемы**: Существующая структура была слишком плоской и не соответствовала общепринятым практикам FastAPI-проектов. Модели, CRUD-операции, API-эндпоинты и бизнес-логика были смешаны, что затрудняло бы дальнейшую разработку.
*   **Принята стандартная архитектура**: Было решено реорганизовать код по принципу разделения ответственности, создав четкую структуру с директориями для `api`, `crud`, `models`, `schemas` и `services`.

### 2.2. Удаление устаревших файлов

*   **Очистка проекта**: Были удалены старые, более не используемые файлы, такие как `backend/database.py`, `backend/models.py`, `backend/api/story.py` и `backend/services/story_service.py`, чтобы избежать путаницы и конфликтов.

### 2.3. Создание новой структуры директорий

*   **`backend/app`**: Создана основная директория `app`, внутри которой разместилась вся логика приложения.
*   **`app/models`**: Перемещены и обновлены модели SQLAlchemy (`Story`, `Scene`, `Panel`, `Character`).
*   **`app/schemas`**: Созданы схемы Pydantic, соответствующие моделям, для валидации данных в API.
*   **`app/crud`**: Выделены функции для прямого взаимодействия с базой данных (Create, Read, Update, Delete).
*   **`app/api`**: Создана новая структура для API-эндпоинтов, разделенная по ресурсам (`story`, `scene` и т.д.).
*   **`app/services`**: Перемещена бизнес-логика, такая как `story_service`.
*   **`app/core`**: Создана директория для конфигурации приложения.

### 2.4. Обновление и адаптация кода

*   **Переписаны импорты**: Все импорты в проекте были обновлены в соответствии с новой структурой.
*   **Адаптирована логика**: Код в сервисах и API-эндпоинтах был скорректирован для работы с новыми путями к моделям, схемам и CRUD-функциям.
*   **Инициализация FastAPI**: Основной файл `main.py` был обновлен для корректной инициализации приложения FastAPI и подключения роутеров из новой директории `api`.
