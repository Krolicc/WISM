# План Разработки: Инструмент Анализа Нарратива

## 1. Цель

Перейти от текущей визуализации графа в виде "клубка данных" к созданию интерактивного инструмента для сценарного анализа. Инструмент должен помогать автору отслеживать развитие сюжета, находить ошибки повествования и анализировать структуру истории.

## 2. Ключевые Функции

### 2.1. Временная Прямая Сюжета (Narrative Timeline)

-   **Концепция:** Основной экран представляет собой временную шкалу, идущую слева направо.
-   **Ось времени:** Состоит из последовательности "сюжетных битов" (частей сцен), которые представляют хронологию истории.
-   **Сюжетные арки:** Поверх временной шкалы отрисовываются кривые (дуги), которые отслеживают "пути" ключевых элементов:
    -   **Арки персонажей:** Показывают появление и участие конкретного персонажа в сюжете.
    -   **Арки отношений:** Отслеживают взаимодействие двух или более персонажей (например, романтическая линия).
    -   **Арки предметов:** Показывают путь важного артефакта через историю.

### 2.2. Нарративный Линтер (Narrative Linter)

-   **Концепция:** Автоматизированная система проверки целостности и логики сюжета.
-   **Типы проверок:**
    -   **Непрерывность (Continuity):** Персонаж в двух местах одновременно; использование утерянного предмета.
    -   **Логика (Causality):** Нарушение причинно-следственных связей; персонаж знает то, чего знать не может.
    -   **Темп и Ритм (Pacing):** Анализ последовательности сцен (например, слишком много сцен одного типа подряд).

## 3. Архитектура Данных (Гибридная Модель)

Для достижения поставленных целей будет использоваться гибридная модель хранения данных, играющая на сильных сторонах разных типов баз данных.

-   **PostgreSQL / MongoDB (Хранилище "Досье"):**
    -   **Назначение:** Хранение полных описаний (атрибутов) сущностей.
    -   **Содержит:** Таблицы/коллекции `Characters`, `Locations`, `Items` с их подробными характеристиками (биография, внешность, история и т.д.).
    -   **Роль:** "Энциклопедия" или "Картотека" мира.

-   **Neo4j / Графовая БД (Хранилище "Связей"):**
    -   **Назначение:** Моделирование и анализ событий, взаимодействий и последовательностей.
    -   **Содержит:**
        -   **Узлы-события:** `(:Event {sequence_id: 1, scene_id: 'xyz'})`
        -   **Связи:** `(:Character)-[:PARTICIPATES_IN]->(:Event)`, `(:Event)-[:LEADS_TO]->(:Event)`.
    -   **Роль:** "Карта приключений", отвечающая за динамику сюжета.

## 4. Структура ответа API для Временной Прямой

Бэкенд предоставит новый эндпоинт (`GET /api/story/{id}/narrative_flow`), который будет возвращать готовую для визуализации структуру.

```json
{
  "key_entities": {
    "characters": [ { "id": "char_1", "name": "Герой" } ],
    "items": [ { "id": "item_1", "name": "Меч" } ]
  },
  "story_beats": [
    {
      "beat_id": 1,
      "scene_id": "scene_abc",
      "summary": "Герой находит Меч в пещере.",
      "present_entity_ids": ["char_1", "item_1"] 
    },
    {
      "beat_id": 2,
      "scene_id": "scene_def",
      "summary": "Герой сражается с драконом.",
      "present_entity_ids": ["char_1", "item_1"]
    }
  ]
}
```

## 5. План Действий

### Фаза 1: Бэкенд

1.  **Проектирование Схем:** Финализировать схемы для PostgreSQL/Mongo и графовой БД в соответствии с гибридной моделью.
2.  **Разработка Логики:** Создать сервисы для анализа текста историй, извлечения событий, персонажей и их связей.
3.  **Создание API:** Реализовать эндпоинт `GET /api/story/{id}/narrative_flow`.
4.  **Разработка Линтера:** Начать реализацию базовых правил проверки (например, на непрерывность).

### Фаза 2: Фронтенд

1.  **Полный рефакторинг `GraphView.vue`:** Переименовать компонент в `NarrativeFlowView.vue` и полностью переписать его для работы с новой структурой API.
2.  **Реализация Временной Прямой:** Отрисовать последовательность `story_beats`.
3.  **Реализация Сюжетных Арок:** Разработать логику для отрисовки кривых Безье, соединяющих `story_beats` для выбранных персонажей или арок.
4.  **Визуализация Ошибок:** Отобразить предупреждения от "Нарративного Линтера" непосредственно на временной прямой.
