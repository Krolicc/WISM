# Обзор проекта

**Имя проекта:** Интеллектуальная платформа для сквозной генерации мультимедийного повествовательного контента (комиксов/сторибордов) с использованием технологий генеративного ИИ

Этот документ содержит обзор структуры проекта, его зависимостей и планов на будущее.

## Структура проекта

Проект представляет собой монорепозиторий, состоящий из двух основных частей:

*   `/frontend`: Приложение на Vue.js для пользовательского интерфейса.
*   `/backend`: Приложение на FastAPI для серверной логики и API.
