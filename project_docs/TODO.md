# Список дел для первой версии приложения

Дата: 27.02.2026

## 0. Техническая база и Инфраструктура
1. **Отслеживание состояния длительных операций**: Внедрить Websockets или long-polling для отслеживания прогресса генерации контента в реальном времени, чтобы пользователь видел, что процесс идет.
2. **Система уведомлений**: Реализовать показ "тостов" (всплывающих уведомлений) для информирования пользователя об успешных операциях (сохранено, сгенерировано) или ошибках.

## 1. Работа с текстовым содержимым
1. **Доработка генерации**: Завершить и отладить функцию догенерации и перегенерации глав, сцен и кадров с использованием флагов. (3\4. Дата: 02.03.2026)
2. **Импорт историй (Самовоспроизводимость)**: Реализовать создание историй из внешних источников:
    1. Из структурированного файла (JSON/YAML) с описанием сюжета.
    2. Из готового рассказа (парсер текста).
    3. Из набора разрозненных идей.
3. **Структурированный редактор промптов**: Заменить простое поле `<textarea>` для детальных промптов на UI-конструктор, где пользователь сможет заполнять поля ("Персонажи", "Место действия", "Реквизит", "Стиль") в структурированном виде.

## 2. Работа с изображениями
1. **Интеграция Image Generation API**: Подключить API для генерации изображений (например, Stable Diffusion, Midjourney API).
2. **Создание кадров**: Реализовать генерацию полноценных кадров на основе общего и детального промпта.
3. **Консистентность персонажей**: Продумать и реализовать механизм для сохранения внешнего вида персонажей между разными кадрами (например, через использование seed, эмбеддингов или LoRA).
4. **Базовый редактор изображений**: Возможность простого редактирования в кадре: кадрирование, добавление текста (диалоговые пузыри).

## 3. Общая логика сайта
1. **Иерархический просмотр**: Создать окно для просмотра текущей истории в виде иерархии текста (История -> Главы -> Сцены).
2. **Создание/Управление персонажами**: Реализовать CRUD для персонажей истории (имя, описание, референсы), которые будут использоваться при генерации.
3. **Frontend CRUD**: Обеспечить полноценное создание, чтение, обновление и удаление для историй, глав, сцен и кадров через интерфейс.
4. **Управление пользователями**:
    1. Регистрация и авторизация (локальная и через Google/соцсети).
    2. Профиль пользователя (список его историй) и базовые настройки.
5. **Главная страница**: Создать приветственную страницу (лендинг) для неавторизованных пользователей.
6. **Онбординг**: Разработать краткое руководство или серию подсказок для новых пользователей, объясняющих основной функционал.

## 4. Экспорт и Публикация
1. **Базовый экспорт**: Реализовать функцию экспорта готовой истории или главы в формате PDF или как набора изображений (JPEG/PNG).
